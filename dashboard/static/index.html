Customize / Bake Cloud Image

Inject packages, software, or configurations directly into the offline QCOW2 image via virt-customize.

Will be saved to /data/isos/ and available for VM deployment.
📸

Create Snapshot & Template Image

Export this instance's current disk state into a compressed template image in /data/isos. You can then launch new VMs using this exact image!

Will be saved to /data/isos/ and available in the Deploy VPS Wizard.
🗜️

Sparsify & Shrink VM Disk

Reclaim host storage by running virt-sparsify on this instance's QCOW2 disk. It inspects the filesystem, removes deleted dirty blocks, zeros unallocated sectors, and shrinks the file on /data/vms/ to its true minimal size.

🌐

Add Virtual Network (Libvirt & NAT)

Define a new virtual bridge network in Libvirt. Dashboard will generate the XML definition, register it via virsh net-define, autostart it, and configure IPTables NAT masquerade automatically.

Convention: net-10.X.Y or custom name.
Linux bridge device (e.g. virbr20).
Host bridge IP address for routing.
Subnet mask (255.255.255.0 = /24).
